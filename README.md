## Task 1 — Accessible Conference Schedule

A responsive two-day conference schedule with three parallel tracks.

Key features:

- Keyboard-accessible navigation
- Visible focus indicators
- Responsive mobile layout
- No horizontal scrolling at 320px
- Accessible session details dialog
- Escape key support
- Focus return after dialog close
- Arrow-key navigation between conference days
